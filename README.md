# Bank-Loan-Analysis
1. Project Title: 
Bank Loan Analysis. 

2. Description:
The Bank Analysis Dashboard is a analytical PowerBI report designed to help users explore and compare the data. Banks generate huge volumes of lending and transaction data. This project turns that raw data into dashboards that help stakeholders monitor portfolio health, repayment, risk and cash flow. It contains Loan portfolio like funded amount, collections, interest, delinquency, default and verification risk.

3. Tech Stack:
PowerBI - Main data visualization platform used for report creationg.
Power Query- Data transformation and cleaning layer for reshaping and preparing the data.
DAX - Used for calculated measures, dynamic visuals and conditional logics.
Data Modeling - Relationships established among tables to enable cross-filtering and aggregations.
File Format - .pbix for development and .png for dashboard preview.

4. Key Visuals:
KPI Cards – Loans 66K; non-verified loans 26%; funded loans 733M; collections 808.3M;
interest 155M; default loans 1K; default loan rate 1.6%; delinquent loans 7K; delinquent loan
rate 10.8%.
Line chart – Disbursement trend.
Doughnut charts – Loan status, loan by product code, loan by religion, loan by age.
Column chart – Loan by grade.
Bar charts – State-wise loan and branch-wise performance.
Slicers – Years, city.

5. Recommendations and Insights:
Delinquency is 10.8%, far above the 1.6% default rate step up early follow-up on overdue loans
26% of loans are not verified: tighten verification before disbursement
Uttar Pradesh, Punjab and Bihar lead lending: watch concentration risk
Loans cluster in grades B and C and ages 26-35: target this core segment
